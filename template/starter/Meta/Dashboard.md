# Dashboard

Live Dataview queries. `Meta/Status.md` is the generated, plugin-free equivalent — run
`zipper status` if you'd rather not rely on the plugin.

## The scoreboard

```dataview
TABLE stage, revenue_to_date AS "$", paying_users, customers
FROM "Projects"
WHERE revenue_intent = true
SORT revenue_to_date DESC
```

Everything meant to earn, and what it has earned. A `0` is a fact; a blank hides the row's
honesty.

## Stale — claims active, note untouched 30+ days

```dataview
TABLE status, note_updated, last_touched
FROM "Projects"
WHERE status = "active" AND date(note_updated) < date(today) - dur(30 days)
SORT note_updated ASC
```

## Said active, but absent from the logs

```dataview
TABLE last_touched
FROM "Projects"
WHERE status = "active" AND (!last_touched OR date(last_touched) < date(today) - dur(21 days))
SORT last_touched ASC
```

The gap between what you call active and what you actually touch. `zipper sync` fills
`last_touched` from `[[links]]` in `Log/`, so this only tells the truth if you log.

## Blocked and open loops

```dataview
TABLE blocked_by, review
FROM "Projects"
WHERE blocked_by OR open_loop = true
```

## Decisions coming due

```dataview
TABLE status, decided, review, confidence
FROM "Decisions"
WHERE review
SORT review ASC
```

Open one and read *What would change my mind*. Has any of it happened?

## Everything under review, anywhere

```dataview
TABLE review, type, status
FROM ""
WHERE review AND date(review) <= date(today) + dur(30 days)
SORT review ASC
```

## The graveyard

```dataview
TABLE stage, revenue_to_date AS "$", ended
FROM "Projects"
WHERE status = "archived" OR status = "retired" OR status = "dormant"
SORT ended DESC
```

Worth rereading before starting the next thing.

## Recent logs

```dataview
TABLE file.mtime AS edited
FROM "Log"
SORT file.name DESC
LIMIT 14
```
