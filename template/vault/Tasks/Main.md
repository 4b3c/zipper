# Main Tasks

Tasks carry `[project:: [[Note]]]` so views can group them by what they serve. Add
`[due:: YYYY-MM-DD]` only when a date is real.

**Titles are five to ten words — the action, nothing else.** Reasons and numbers go on
indented lines underneath, which the dashboard shows as the row's description.
