# Now

The one page to open in the morning. Everything here is live — nothing is hand-maintained.

## Flagged next

Tasks tagged `#next`. Keep this under five. If it's longer, you haven't chosen.

```dataview
TASK
FROM "Tasks"
WHERE !completed AND contains(tags, "#next")
```

## Every open task, by project

```dataview
TASK
FROM "Tasks"
WHERE !completed
GROUP BY project
```

## The next action on every active project

The single most useful query in the vault. If a row is blank, that project is drifting.

```dataview
TABLE WITHOUT ID file.link AS Project, stage AS Stage, next_action AS "Next action"
FROM "Projects"
WHERE status = "active"
SORT stage ASC
```

## Blocked

```dataview
TABLE WITHOUT ID file.link AS Project, blocked_by AS "Blocked by"
FROM "Projects"
WHERE blocked_by
```

## Anything due for review in the next 30 days

```dataview
TABLE WITHOUT ID file.link AS Note, review AS Review, type AS Type
FROM ""
WHERE review AND date(review) <= date(today) + dur(30 days)
SORT review ASC
```

## Open decisions

```dataview
TABLE WITHOUT ID file.link AS Decision, decided AS Decided, review AS Review, confidence AS Confidence
FROM "Decisions"
WHERE status = "open"
```
