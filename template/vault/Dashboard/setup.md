# Setting up

The dashboard's "setting up" card shows this list. Claude ticks each item off as
setup gets there; when they are all done, remove the card from `settings.json`.

- [ ] Say who you are (name, timezone)
- [ ] Make the Discord bot and save its token
- [ ] Choose how the zipper's Claude logs in
- [ ] Go through the plugins
- [ ] Start the zipper
- [ ] Send it a first message on Discord
- [ ] Write down what this vault is for
