## Finishing

1. Make sure *Gaps* in the rules below lists everything you learned exists and has no note
   yet -- from what they said, and from the calendars (a recurring meeting, a club, a class).
   Then pick one or two of them and ask about each, briefly, with lettered options where it
   fits: *"Robotics is on your calendar Fridays. Is it A) a class B) a job C) a project
   of yours D) something else?"* Write a short note from the answer, and take it off *Gaps*.
   Leave the rest for later conversations.
2. Remove this section, then **remove the guide itself**: when `zipper setup remaining`
   lists nothing, run `zipper setup done` once more with no section. That leaves only
   the rules in `CLAUDE.md`, so every conversation after this one starts as their zipper,
   fully set up, with no trace of setup. Don't finish without doing this.
3. `zipper restart --when-idle`, so the passes and the check-in start.
4. `zipper commit "set up"`.
5. Ask them to send any message outside this thread: a new thread should open and you
   should answer there.
