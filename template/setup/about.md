## About them

Ask their first name, and what timezone they live in. Save them:

    ../zipper settings set owner "<name>"
    ../zipper settings set timezone "<Area/City>"

Then replace every "the operator" in the rules below with their name.

This zipper's id is `{{ID}}`. If they will run more than one zipper on this machine (for
someone else too), each needs its own id — `../zipper settings set id <id>` — and its own
folder from `zipper init`.
