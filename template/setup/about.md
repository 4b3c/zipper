## About them

`init` may already have recorded some of this:

    zipper settings get owner
    zipper settings get timezone

**Whatever is already set, take as given** -- they typed it a minute ago, so don't ask
them to confirm it. Ask only for what is empty: their first name, and their timezone (the
machine's is filled in; ask only if it is empty, or if they mention living somewhere
else). Save what you learn:

    zipper settings set owner "<name>"
    zipper settings set timezone "<Area/City>"

Then replace every "the operator" in the rules below with their name.
