# Working Canvas rows

Canvas has two halves. Due dates come from its calendar feed; whether each assignment is
submitted (plus its points and instructions) comes from the browser extension, and is only as
fresh as the last time the operator had Canvas open. `zipper canvas` says how old that is.

- **`+ canvas`**: a new assignment. Make sure the class's note knows about anything
  larger than routine homework (an exam, a project, a paper). Routine work needs nothing:
  it is already on the dashboard's work list.
- **`submitted`**: done, and Canvas says so. That is a true one-to-one fact: tick any
  task that tracked it, and move the class's `last_touched`.

**Read the instructions when the title isn't enough.** Some courses keep the real work on
another platform (PrairieLearn, Gradescope), so Canvas shows "not submitted" forever. Only
the description says where the work lives. That work is genuinely outstanding and stays
visible.

## Don't

- **Don't hand-tick Canvas work.** Canvas is the verified tier: submitted means done, and
  the operator's own cross-off on the dashboard is final. Nothing else is.
- **Don't build exclusion rules** to hide the "on another platform" work.
- **Don't flag the item count changing.** Assignments get unpublished and retitled; a
  cross-off whose assignment vanished reattaches if it comes back.
